 # Spotify Clone 🎵

A Spotify-inspired music streaming website built using **HTML, CSS, and JavaScript**.

The project focuses on recreating the look and feel of Spotify while implementing basic music-player functionality such as play/pause controls, song selection, and a responsive layout.

## Features
- 🎵 Spotify-inspired user interface
- ▶️ Play and pause music
- 🎧 Song selection and playback
- 📱 Responsive design for different screen sizes
- 🧭 Sidebar navigation
- 🎨 Dark-themed Spotify-style design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to practice **frontend web development, responsive design, CSS layouts, and JavaScript DOM manipulation**.
